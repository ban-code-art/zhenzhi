# 针灸学习 APP · 数据模型

> 单机 SQLite（Room），全部字段已按推荐方案定稿。
> 通用约定：主键 `id INTEGER PK 自增`；字段 `snake_case`；时间用 Unix 毫秒；布尔用 `0/1`。

## 1. users（用户）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK 自增 | |
| username | TEXT | NOT NULL，唯一 | 登录名 |
| password_hash | TEXT | NOT NULL | 密码散列，不存明文 |
| salt | TEXT | NOT NULL | 随机盐（hex） |
| nickname | TEXT | 可空 | 昵称，默认用用户名 |
| avatar_id | INTEGER | NOT NULL，默认 0 | 头像：0=昵称首字或自定义图，1–6=内置头像 |
| avatar_path | TEXT | 可空 | 自定义头像文件名（相对 `files/avatars/`；为空则用内置头像） |
| created_at | INTEGER | NOT NULL | 注册时间 |
| updated_at | INTEGER | NOT NULL | 最近修改时间 |

索引：`UNIQUE(username)`

## 2. chapters（知识章节）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK 自增 | |
| order_index | INTEGER | NOT NULL，唯一 | 章节顺序 1–7 |
| title | TEXT | NOT NULL | 章节标题 |
| summary | TEXT | 可空 | 章节摘要 |
| content_key | TEXT | NOT NULL | 图文资源标识（正文作为静态资源打包，不入库） |
| enabled | INTEGER | NOT NULL，默认 1 | 是否启用 |
| created_at | INTEGER | NOT NULL | |

索引：`UNIQUE(order_index)`

## 3. questions（题库）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK 自增 | |
| type | TEXT | NOT NULL | `CHOICE` / `JUDGE` / `FILL` / `ESSAY` |
| chapter_id | INTEGER | FK → chapters.id，可空 | 所属章节 |
| stem | TEXT | NOT NULL | 题干 |
| options | TEXT | 可空 | 选择题选项，JSON 数组 |
| answer | TEXT | NOT NULL | 标准答案，按题型存结构化 JSON（见下表） |
| synonyms | TEXT | 可空 | 同义词表，JSON（仅填空，按空组织，独立字段） |
| knowledge_point | TEXT | 可空 | 知识点标签 |
| analysis | TEXT | NOT NULL | 解析 |
| score | INTEGER | NOT NULL，默认 2 | 默认分值（选择/判断 2，填空/应用 4） |
| enabled | INTEGER | NOT NULL，默认 1 | 是否启用 |
| created_at | INTEGER | NOT NULL | |

索引：`(type)`、`(chapter_id)`、`(type, enabled)`

`answer` 结构：

| 题型 | 存储内容 | 示例 |
| --- | --- | --- |
| CHOICE | 正确选项标识 | `"A"` |
| JUDGE | 布尔 | `"true"` |
| FILL | 每空一个标准答案 | `["丰隆"]` / `["中脘","足三里"]` |
| ESSAY | 得分要点数组 | `["辨证为脾胃虚寒证","治则温中散寒、健脾和胃","主选中脘、足三里、内关","操作以补法为主，配合艾灸"]` |

`synonyms` 结构（与 `answer` 的空一一对应）：

```json
[["丰隆", "丰隆穴"], ["中脘", "中脘穴"]]
```

## 4. test_records（测试记录）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK 自增 | |
| user_id | INTEGER | FK → users.id | 所属用户 |
| paper_type | TEXT | NOT NULL | `RANDOM` / `FAVORITE` |
| status | TEXT | NOT NULL | `IN_PROGRESS` / `SUBMITTED` / `ABANDONED` |
| started_at | INTEGER | NOT NULL | 开始时间 |
| submitted_at | INTEGER | 可空 | 交卷时间 |
| duration_limit_seconds | INTEGER | NOT NULL，默认 2400 | 限时 40 分钟 |
| remaining_seconds | INTEGER | 可空 | 断点续答剩余秒数，提交后置空 |
| used_seconds | INTEGER | 可空 | 实际用时 |
| total_score | INTEGER | 可空 | 总分 |
| choice_score | INTEGER | 可空 | 选择题得分 |
| judge_score | INTEGER | 可空 | 判断题得分 |
| fill_score | INTEGER | 可空 | 填空题得分 |
| essay_score | INTEGER | 可空 | 应用题得分 |
| created_at | INTEGER | NOT NULL | |

索引：`(user_id, started_at)`

## 5. test_answers（作答明细）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK 自增 | |
| test_id | INTEGER | FK → test_records.id，级联删除 | 所属测试 |
| question_id | INTEGER | FK → questions.id | 题目 |
| order_index | INTEGER | NOT NULL | 题序 |
| user_answer | TEXT | 可空 | 用户原始作答 |
| score | INTEGER | NOT NULL，默认 0 | 本题得分 |
| is_correct | INTEGER | 可空 | 1 对 / 0 错 / 空 = 部分正确或未判定 |

索引：`UNIQUE(test_id, question_id)`、`(test_id)`

## 6. favorites（收藏 / 错题）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK 自增 | |
| user_id | INTEGER | FK → users.id | 所属用户 |
| question_id | INTEGER | FK → questions.id | 题目 |
| source | TEXT | NOT NULL | `MANUAL`（手动收藏）/ `WRONG`（错题收录） |
| created_at | INTEGER | NOT NULL | 收藏时间 |

索引：`UNIQUE(user_id, question_id, source)`、`(user_id, source)`
说明：同一题可同时存在 `MANUAL` 与 `WRONG` 两条记录，展示时按题目聚合去重。

## 7. study_progress（学习进度）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | INTEGER | PK 自增 | |
| user_id | INTEGER | FK → users.id | 所属用户 |
| chapter_id | INTEGER | FK → chapters.id | 章节 |
| completed | INTEGER | NOT NULL，默认 0 | 是否完成学习 |
| quiz_score | INTEGER | 可空 | 随堂测得分 |
| quiz_total | INTEGER | 可空 | 随堂测总分 |
| updated_at | INTEGER | NOT NULL | 最近更新 |

索引：`UNIQUE(user_id, chapter_id)`
说明：随堂测成绩不计入随机测试总分。

## 表关系

```
users 1 ──< test_records 1 ──< test_answers >── 1 questions
users 1 ──< favorites >── 1 questions
users 1 ──< study_progress >── 1 chapters
chapters 1 ──< questions
```
