# 针灸学习 APP · 需求说明

> 版本：v1.0 ｜ 日期：2026-10-18 ｜ 状态：初稿（随开发更新）
> 项目类型：课业实践项目 ｜ 团队规模：3 人

---

## 1. 项目概述

面向针灸知识初学者的 Android 单机学习应用，以"随时随地随机测试"为核心，辅以知识学习、题目记录与个人成绩管理，形成"学习 → 测试 → 复习"闭环。

- **目标**：完成一款可实际运行、完全离线的单机 APP。
- **核心指标**：随机测试 40 题 / 100 分；题库 ≥240 题；知识学习 ≥7 章。
- **技术形态**：Android 原生（Kotlin + Jetpack Compose），本地 Room/SQLite，无服务器。

> 内容声明：应用内针灸知识仅供学习参考，不构成任何医疗建议或诊疗依据。

---

## 2. 目标用户与使用场景

**目标用户**：中医药专业低年级学生、针灸爱好者等初学者。

**典型场景**：

- 学完一章后做随堂测检验掌握情况；
- 利用碎片时间做一次 40 题随机测试；
- 考前集中复习收藏题目与错题；
- 在「我的」查看历史成绩，追踪学习变化。

---

## 3. 范围与边界

### 3.1 范围内

- 单角色普通用户；
- 账号、题库、成绩、收藏等数据全部保存在本机；
- 题库与图文内容随应用内置；
- 完全离线，无需网络与服务器。

### 3.2 范围外

- 后台管理端、多角色权限；
- 账号跨设备同步；
- 手机号/邮箱验证码、微信/第三方登录；
- 在线题库更新、云备份。

> 说明：登录方式采用**用户名 + 密码**，与离线单机定位及数据模型一致。

---

## 4. 功能需求

需求编号规则：`FR-模块-序号`。优先级：P0 必须 / P1 重要 / P2 可选。

### 4.1 账号与认证

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-A-01 | 注册：用户名 + 密码（可填昵称） | P0 | 用户名唯一、格式校验、密码强度校验；密码加盐散列入库，不存明文 |
| FR-A-02 | 登录：校验用户名与密码 | P0 | 错误时给出明确提示；成功后进入主界面 |
| FR-A-03 | 登录状态保持 | P0 | 再次打开应用直接进入主界面 |
| FR-A-04 | 登出：设置页退出 | P0 | 清除会话并回到登录页；重启后不再自动登录 |
| FR-A-05 | 修改密码 | P0 | 校验原密码；新密码符合规则；二次确认一致 |
| FR-A-06 | 修改昵称 | P1 | 昵称长度校验；保存后「我的」页即时更新 |
| FR-A-07 | 切换头像 | P1 | 个人信息页提供 6 个内置头像、默认头像，并支持从相册上传图片；保存后同步到「我的」页 |

### 4.2 首页与导航

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-N-01 | 登录后进入主界面 | P0 | 未登录进入登录页，已登录进入主界面 |
| FR-N-02 | 底部导航四页 | P0 | 知识学习 / 随机测试 / 记录题目 / 我的，可切换且保留状态 |
| FR-N-03 | 子页导航与返回 | P0 | 「我的」子页带返回；支持系统返回键；列表→详情可返回列表 |

### 4.3 知识学习

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-K-01 | 章节列表（7 章） | P0 | 按顺序展示章节标题 |
| FR-K-02 | 章节图文详情 | P0 | 图文内容随包内置，可阅读 |
| FR-K-03 | 章节随堂测 | P0 | 每章 5–10 题，提交后显示得分与解析 |
| FR-K-04 | 学习进度 | P1 | 记录完成状态与随堂测成绩（不计入随机测试总分） |

### 4.4 随机测试

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-T-01 | 随机组卷 | P0 | 40 题：选择 20 / 判断 10 / 填空 5 / 应用 5；同卷不重复；按题型顺序 |
| FR-T-02 | 答题交互 | P0 | 选择单选、判断对错、填空/应用文本输入 |
| FR-T-03 | 计时 | P0 | 40 分钟倒计时；剩余 5 分钟提示；到时自动交卷 |
| FR-T-04 | 断点续答 | P1 | 中途退出保存进度与剩余时间，恢复同一份试卷 |
| FR-T-05 | 交卷判分 | P0 | 满分 100；填空同义词、应用按要点折算；未作答计 0 |
| FR-T-06 | 结果回顾 | P0 | 逐题查看题干、我的作答、答案/要点、知识点、解析 |
| FR-T-07 | 成绩留存 | P0 | 自动记入「我的 → 学习记录（测试成绩）」 |

### 4.5 记录题目

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-R-01 | 手动收藏 | P1 | 测试回顾中可逐题收藏 |
| FR-R-02 | 错题自动收录 | P1 | 答错题目自动进入错题本，与收藏以标签区分 |
| FR-R-03 | 题目详情 | P1 | 查看题干、答案/要点、知识点、解析 |
| FR-R-04 | 收藏题重练 | P2 | 收藏题组成小测 |
| FR-R-05 | 题目管理 | P1 | 可移除收藏/错题 |

### 4.6 我的

| 编号 | 需求 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| FR-M-01 | 个人信息 | P1 | 查看用户名、修改昵称 |
| FR-M-02 | 学习统计 | P1 | 学习天数、连续打卡、已完成章节、收藏数、错题数 |
| FR-M-03 | 成绩列表 | P0 | 按时间倒序展示时间、得分、用时、各题型得分 |
| FR-M-04 | 成绩详情 | P0 | 逐题回顾；数据来自 `test_answers` |
| FR-M-05 | 设置 | P0 | 个人信息、修改密码、关于、退出登录 |

## 5. 数据需求

核心表（详见 `docs/数据模型评审.md`）：

| 表 | 说明 |
| --- | --- |
| users | 用户：用户名、密码散列、盐、昵称 |
| chapters | 章节元数据；正文以静态资源打包 |
| questions | 题库：题型、题干、选项、答案/要点、同义词、解析 |
| test_records | 测试记录：状态、时间、用时、总分与各题型得分 |
| test_answers | 作答明细：题序、作答、得分、正误 |
| favorites | 收藏/错题：来源标签与时间 |
| study_progress | 学习进度：完成状态、随堂测成绩 |

- 数据库：`acupuncture.db`，Room v1，外键开启，schema 导出留档。
- 所有数据仅存本机；卸载应用即清空。

## 6. 非功能需求

| 编号 | 类别 | 要求 |
| --- | --- | --- |
| NFR-01 | 离线 | 全部功能无网络依赖 |
| NFR-02 | 安全 | 密码 PBKDF2 加盐散列；不存明文、不上传 |
| NFR-03 | 性能 | 页面切换流畅；查询走 DAO 索引；大数据量用 LazyColumn |
| NFR-04 | 兼容 | Android 7.0（API 24）及以上 |
| NFR-05 | 易用 | 中文界面；错误提示明确；空状态友好 |
| NFR-06 | 可维护 | 分层架构；Repository 隔离数据访问 |
| NFR-07 | 合规 | 显著位置展示"仅供学习参考"声明 |

## 7. 验收标准（P0）

1. 注册 → 登录 → 主界面全流程可用，密码不以明文存储。
2. 杀进程重开仍保持登录；退出登录后回到登录页且不再自动登录。
3. 底部四页可切换；「我的」子页可进入并返回。
4. 修改密码后：新密码可登录、旧密码失败。
5. 随机测试 40 题、满分 100、按时交卷、成绩入库并可回顾。
6. 收藏与错题可在「记录题目」查看并移除。
7. 应用可在无网络、无电脑连接的手机上独立运行。
